Contribute

OpenReliant is a free fan project, and every bit of help moves it forward. You don't need to write code to help.

Write code

Pick an issue, fix a bug or port a part of the original game. Issues marked good first issue are a good place to start. Before you begin, read CONTRIBUTING.md: it explains how the code is organised, how to build and test it, and how pull requests work.

You may use an LLM to help you write code. You need to understand what you send, have tested it, and be able to explain it. Purely vibe-coded changes won't be accepted.

Play and report bugs

Play the game and tell us what goes wrong. A good bug report says what you did, what happened, and what you expected, and includes the log. If you can, check what the original game does in the same situation: OpenReliant aims to match it.

Report a bug on GitHub. Missing something? Ask for a feature.

Make mods

New ships, sharper textures, sounds and scripts make the game better for everyone. The modding guide shows how to make one. Good mods that are free to share can go on the mods site.

The example mods that show mod makers how each feature works have some gaps. Writing one of them is a good first issue.

Improve the docs

The documentation covers installing and playing, modding, the engine and the game's file formats. If something is unclear, missing or wrong, a fix is very welcome.

Star it on GitHub

A star costs nothing and helps other StarLancer fans find the project. Telling a friend who loved the game helps too.

Star OpenReliant on GitHub.
